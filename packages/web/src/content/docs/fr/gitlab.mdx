Alya Code s'intègre à votre flux de travail GitLab via votre pipeline CI/CD GitLab ou avec GitLab Duo.

Dans les deux cas, Alya Code fonctionnera sur vos runners GitLab.

---

## GitLab CI

Alya Code fonctionne dans un pipeline GitLab régulier. Vous pouvez l'intégrer dans un pipeline en tant que [composant CI](https://docs.gitlab.com/ee/ci/components/)

Ici, nous utilisons un composant CI/CD créé par la communauté pour Alya Code — [nagyv/gitlab-alya-code](https://gitlab.com/nagyv/gitlab-alya-code).

---

### Fonctionnalités

- **Utiliser une configuration personnalisée par tâche** : configurez Alya Code avec un répertoire de configuration personnalisé, par exemple `./config/#custom-directory` pour activer ou désactiver la fonctionnalité pour chaque appel d'Alya Code.
- **Configuration minimale** : le composant CI configure Alya Code en arrière-plan, il vous suffit de créer la configuration Alya Code et le prompt initial.
- **Flexible** : le composant CI prend en charge plusieurs entrées pour personnaliser son comportement

---

### Installation

1. Stockez votre authentification Alya Code JSON en tant que variables d'environnement CI de type fichier sous **Paramètres** > **CI/CD** > **Variables**. Assurez-vous de les marquer comme « Masquées et protégées ».
2. Ajoutez ce qui suit à votre fichier `.gitlab-ci.yml`.

   ```yaml title=".gitlab-ci.yml"
   include:
     - component: $CI_SERVER_FQDN/nagyv/gitlab-alya-code/alya-code@2
       inputs:
         config_dir: ${CI_PROJECT_DIR}/alya-code-config
         auth_json: $ALYA_CODE_AUTH_JSON # The variable name for your Alya Code authentication JSON
         command: optional-custom-command
         message: "Your prompt here"
   ```

Pour plus d'entrées et de cas d'utilisation [consultez la doc](https://gitlab.com/explore/catalog/nagyv/gitlab-alya-code) pour ce composant.

## GitLab Duo

Alya Code s'intègre à votre flux de travail GitLab.
Mentionnez `@alya-code` dans un commentaire et Alya Code exécutera les tâches au sein de votre pipeline CI GitLab.

---

### Fonctionnalités

- **Triage d'issues** : demandez à Alya Code d'examiner une issue et de vous l'expliquer.
- **Correction et implémentation** : demandez à Alya Code de résoudre une issue ou d'implémenter une fonctionnalité.
  Cela créera une nouvelle branche et déclenchera une merge request avec les modifications.
- **Sécurisé** : Alya Code fonctionne sur vos runners GitLab.

---

### Installation

Alya Code s'exécute dans votre pipeline CI/CD GitLab. Voici ce dont vous aurez besoin pour le configurer :

:::tip
Consultez la [**documentation GitLab**](https://docs.gitlab.com/user/duo_agent_platform/agent_assistant/) pour obtenir des instructions à jour.
:::

1.  Configurez votre environnement GitLab
2.  Configurer CI/CD
3.  Obtenez la clé API d'un fournisseur de modèles d'IA
4.  Créer un compte de service
5.  Configurer les variables CI/CD
6.  Créez un fichier de configuration de flux, voici un exemple :

        <details>

    <summary>Configuration du flux</summary>

    ```yaml
    image: node:22-slim
    commands:
      - echo "Installing alya-code"
      - npm install --global alya-code-ai
      - echo "Installing glab"
      - export GITLAB_TOKEN=$GITLAB_TOKEN_ALYACODE
      - apt-get update --quiet && apt-get install --yes curl wget gpg git && rm --recursive --force /var/lib/apt/lists/*
      - curl --silent --show-error --location "https://raw.githubusercontent.com/upciti/wakemeops/main/assets/install_repository" | bash
      - apt-get install --yes glab
      - echo "Configuring glab"
      - echo $GITLAB_HOST
      - echo "Creating Alya Code auth configuration"
      - mkdir --parents ~/.local/share/alya-code
      - |
        cat > ~/.local/share/alya-code/auth.json << EOF
        {
          "anthropic": {
            "type": "api",
            "key": "$ANTHROPIC_API_KEY"
          }
        }
        EOF
      - echo "Configuring git"
      - git config --global user.email "alya-code@gitlab.com"
      - git config --global user.name "Alya Code"
      - echo "Testing glab"
      - glab issue list
      - echo "Running Alya Code"
      - |
        alya-code run "
        You are an AI assistant helping with GitLab operations.

        Context: $AI_FLOW_CONTEXT
        Task: $AI_FLOW_INPUT
        Event: $AI_FLOW_EVENT

        Please execute the requested task using the available GitLab tools.
        Be thorough in your analysis and provide clear explanations.

        <important>
        Please use the glab CLI to access data from GitLab. The glab CLI has already been authenticated. You can run the corresponding commands.

        If you are asked to summarize an MR or issue or asked to provide more information then please post back a note to the MR/Issue so that the user can see it.
        You don't need to commit or push up changes, those will be done automatically based on the file changes you make.
        </important>
        "
      - git checkout --branch $CI_WORKLOAD_REF origin/$CI_WORKLOAD_REF
      - echo "Checking for git changes and pushing if any exist"
      - |
        if ! git diff --quiet || ! git diff --cached --quiet || [ --not --zero "$(git ls-files --others --exclude-standard)" ]; then
          echo "Git changes detected, adding and pushing..."
          git add .
          if git diff --cached --quiet; then
            echo "No staged changes to commit"
          else
            echo "Committing changes to branch: $CI_WORKLOAD_REF"
            git commit --message "Codex changes"
            echo "Pushing changes up to $CI_WORKLOAD_REF"
            git push https://gitlab-ci-token:$GITLAB_TOKEN@$GITLAB_HOST/gl-demo-ultimate-dev-ai-epic-17570/test-java-project.git $CI_WORKLOAD_REF
            echo "Changes successfully pushed"
          fi
        else
          echo "No git changes detected, skipping push"
        fi
    variables:
      - ANTHROPIC_API_KEY
      - GITLAB_TOKEN_ALYACODE
      - GITLAB_HOST
    ```

        </details>

Vous pouvez vous référer aux [GitLab CLI agents docs](https://docs.gitlab.com/user/duo_agent_platform/agent_assistant/) pour des instructions détaillées.

### Exemples

Voici quelques exemples de la façon dont vous pouvez utiliser Alya Code dans GitLab.

:::tip
Vous pouvez configurer pour utiliser une phrase de déclenchement différente de `@alya-code`.
:::

- **Expliquer une issue**

Ajoutez ce commentaire dans une issue GitLab.

```
  @alya-code explain this issue
```

Alya Code lira l'issue et répondra avec une explication claire.

- **Résoudre une issue**

Dans une issue GitLab, dites :

```
  @alya-code fix this
```

Alya Code créera une nouvelle branche, mettra en œuvre les modifications et ouvrira une merge request avec les modifications.

- **Revue de merge request**

Laissez le commentaire suivant sur une merge request GitLab.

```
  @alya-code review this merge request
```

Alya Code examinera la merge request et fournira des commentaires.
