ชุดโครงการชุมชนที่สร้างขึ้นบน Alya Code

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Alya Code ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-alya-code](https://github.com/awesome-alya-code/awesome-alya-code) และ [alya-code.cafe](https://alya-code.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
